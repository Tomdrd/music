🌿 Sobre o Projeto

Este projeto nasceu em uma aula prática do curso de Análise e Desenvolvimento de Sistemas (ADS), durante o terceiro semestre. A proposta inicial era simples e direta: aplicar os conhecimentos adquiridos em HTML, CSS e JavaScript em um exercício criativo e funcional.

No entanto, o desafio virou inspiração. Decidi ir além e transformar essa atividade em uma experiência interativa e musical, utilizando ferramentas de inteligência artificial para compor uma música educativa sobre a estrutura básica do HTML. A estética visual também ganhou atenção especial, sendo aprimorada com um tema reggae — escolhido para acompanhar o ritmo leve e envolvente da composição.

Todo o desenvolvimento foi realizado em ambiente Linux (Ubuntu), utilizando o editor Visual Studio Code para codificação e o Inkscape para ajustes gráficos e vetoriais. O resultado é uma fusão entre tecnologia, arte e aprendizado, pensada para tornar o estudo da web mais acessível, divertido e memorável.
